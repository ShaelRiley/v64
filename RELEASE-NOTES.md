## Video 64 v0.1.0-alpha.2

Current Linux developer prerelease built from tested source commit `fbd8fbbe1b385ca8cef2eb4fd789c06090004f12`.

This advances beyond the intentionally silent first playable release with native subtitle and AM1 audio playback, feature-length A/V synchronization evidence, stable Rust API/CLI/C ABI, the Linux Video64 Drop shell, bounded long-form source-audio encoding, sampled size estimation, decoded preview generation, and a deterministic audiovisual sample.

Assets include the current native player, a smoke-tested Video64 Drop developer bundle, a complete sample/evidence bundle, the directly playable sample, a manifest, and SHA-256 checksums.

This remains a prerelease. AM1 8 kbps is provisional pending genuine blinded listening. Preview and estimation are not yet presented in the SDL2 window. Video64 Drop still requires system Node.js, FFmpeg/FFprobe, and SDL2. Windows and macOS packages are not included.
