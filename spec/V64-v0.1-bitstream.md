# V64 v0.1 proof bitstream

Status: implemented experimental profile. Integers are unsigned little-endian
unless specified. This document describes the bytes emitted by the JavaScript
proof codec; it is not yet the frozen V64 v1 specification.

## Timing and limits

The timeline tick rate is 60,000 ticks/second. A file declares exactly one
cadence identifier:

| ID | fps rational | ticks/frame |
|---:|---:|---:|
| 0 | 1/10 | 600,000 |
| 1 | 1/2 | 120,000 |
| 2 | 1/1 | 60,000 |
| 3 | 3/1 | 20,000 |
| 4 | 6/1 | 10,000 |
| 5 | 12/1 | 5,000 |
| 6 | 15/1 | 4,000 |
| 7 | 24/1 | 2,500 |
| 8 | 30/1 | 2,000 |
| 9 | 48/1 | 1,250 |
| 10 | 60/1 | 1,000 |

Core proof-decoder limits are 512 columns, 512 rows, 262,144 cells, 64 MiB per
stored chunk, and 1 GiB after payload inflation.

## Fixed 128-byte header

| Offset | Size | Meaning |
|---:|---:|---|
| 0 | 8 | `56 36 34 00 0D 0A 1A 0A` |
| 8 | 1 | major version (`0`) |
| 9 | 1 | minor version (`1`) |
| 10 | 2 | header size (`128`) |
| 12 | 4 | feature flags |
| 16 | 2 | columns |
| 18 | 2 | rows |
| 20 | 1 | cadence ID |
| 21 | 1 | palette-depth ID |
| 22 | 1 | glyph coding mode (`0` = canonical 64) |
| 23 | 1 | reserved, zero |
| 24 | 4 | tick rate (`60000`) |
| 28 | 8 | duration in ticks |
| 36 | 32 | SHA-256 of the 1,024 canonical glyph-mask bytes |
| 68 | 32 | SHA-256 of 768 master-palette bytes |
| 100 | 8 | byte offset of `INDX` chunk |
| 108 | 4 | complete `INDX` chunk length |
| 112 | 4 | chunk count, including `INDX` |
| 116 | 4 | maximum stored payload length |
| 120 | 4 | glyph asset numeric ID (`1`) |
| 124 | 4 | palette asset numeric ID (`1`, candidate profile) |

Reserved fields and unknown mandatory feature bits must be zero.

## Chunk framing

Every chunk has a 32-byte prefix:

| Offset | Size | Meaning |
|---:|---:|---|
| 0 | 4 | ASCII chunk type |
| 4 | 4 | flags: bit 0 CRC present; bit 1 raw DEFLATE |
| 8 | 8 | start timestamp in ticks |
| 16 | 8 | duration in ticks |
| 24 | 4 | stored payload length |
| 28 | 4 | CRC-32 of the stored payload |

The parser rejects invalid ASCII types, unknown flags, CRC mismatches, excessive
lengths, truncation, decompression over 1 GiB, and non-monotonic media chunks.

Registered types:

- `VFRM`: a cell-state keyframe or delta frame;
- `RPTF`: no payload; retain the current complete cell state for its duration;
- `SILN`: no payload; output exact zero-valued mono samples for its duration;
- `PLIT`: one or more bounded deterministic particle-lighting events;
- `META`: inert UTF-8 JSON, never executed and never used to fetch resources;
- `INDX`: seek entries for keyframes.

Unknown uppercase chunk types are mandatory and rejected. Unknown lowercase
types are optional and skipped.

## `VFRM` payload

The first byte is frame kind: `0` keyframe, `1` delta. It is followed by a
command stream terminated by `END`.

Unsigned integers inside command streams use canonical unsigned LEB128, limited
to 32 bits and five bytes. A token is three bytes:
`glyph_index, foreground_palette_index, background_palette_index`.

| Opcode | Name | Operands |
|---:|---|---|
| `00` | `END` | none |
| `01` | `SKIP` | cell count |
| `02` | `LITERAL` | count, then `count` tokens |
| `03` | `REPEAT_TOKEN` | count, then one token |
| `04` | `FILL_RECT` | x, y, width, height, then one token |
| `05` | `DEFINE_TOKEN_DICTIONARY` | count (1–64), then tokens |
| `06` | `DICTIONARY_LITERAL` | count, then `count` dictionary indices |

Sequential commands advance a row-major cursor. `FILL_RECT` does not advance the
cursor. Keyframes begin from all-zero cells and must define every cell;
delta frames begin from the preceding state and may skip. A decoder rejects
overflowing runs, rectangles outside the grid, invalid glyphs/colors, undefined
dictionaries, invalid dictionary indices, missing `END`, and trailing bytes.

## `PLIT` payload

Byte 0 is event count (0–64). Each 20-byte event contains:

`class:u8, color:u8, x:u16, y:u16, intensity:u8, radius:u8,
lifetime_ticks:u32, direction:i16, spread:u16, seed:u32`.

Classes 0–5 are Burst, Spark, Aura, Ray, Phosphor Trail, and Contour Flash.
Coordinates are unsigned 0.16 normalized positions. Intensity and radius are
0–255 normalized values. Direction is signed turns/32768. Simulation is
optional to display but event parsing is mandatory and bounded.

## `INDX` payload

The first four bytes are entry count. Each 20-byte entry is
`timestamp:u64, file_offset:u64, flags:u32`; flag bit 0 marks a keyframe.
Offsets must point to the start of a `VFRM` chunk.

## Asset identity

`V64-GLYPHS-VIDEO64-1` is exactly the ordered 1,024 bytes extracted from ANSI
Tube v0.9.9 `core.js`. Names are metadata; byte order is 64 glyphs × 16 rows,
MSB-left.

The proof encoder uses `V64-P256-CANDIDATE-1`, generated deterministically by
`tools/palette-generator.mjs`. It is immutable under that candidate identifier,
but it must not be renamed to normative `V64-P256-1` until corpus selection is
complete.
